Milat ve Ötesi

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

🇬🇧 English

Milat ve Ötesi is a game project developed for the Teknofest competition. This repository contains the project's website, used for showcasing the game and tracking related data.

The website handles game promotion, a video gallery, and displays data (scores, stats, etc.) sent from the Unity game via Firebase Firestore.

Tech stack: HTML, CSS, JavaScript, Firebase Firestore, GitHub Pages / Firebase Hosting
